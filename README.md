# torchdiagram

Generate publication-ready architecture diagrams directly from PyTorch model code — no manual redrawing, no full LaTeX toolchain required to preview.

## Why

Existing tools in this space are either abandoned (PlotNeuralNet, NN-SVG) or never solved code-to-diagram automation for arbitrary `nn.Module.forward()` code (only sequential/feed-forward models). See `docs/research.md` for the full landscape analysis.

## Status

Early scaffolding — not yet functional.
